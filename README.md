# Booking System — Telegram Bot

Telegram-бот для бронирования рабочих мест в коворкингах, офисах и других пространствах с гибридным форматом работы. Один из двух независимых интерфейсов доступа к системе бронирования (второй — веб-приложение на Flask, см. отдельный репозиторий), реализован как дипломный проект (ВКР, бакалавриат, ИВТ).

> Бот и веб-приложение работают полностью независимо друг от друга: у каждого своя база данных, своя схема таблиц и свой цикл жизни. Отказ одного компонента не влияет на работу другого.

## Возможности

**Пользователь**
- Просмотр списка доступных рабочих мест
- Бронирование места: выбор рабочего места → выбор даты начала через интерактивный календарь → указание количества дней (от 1 до 5)
- Просмотр своих активных бронирований
- Отмена собственного бронирования

**Администратор** (дополнительно к правам пользователя)
- Просмотр всех бронирований в системе
- Отмена любого бронирования
- Добавление и удаление рабочих мест (с подтверждением при наличии связанных броней и опцией каскадного удаления)
- Просмотр статистики: общее количество бронирований, число уникальных пользователей, топ-5 популярных мест

**Супер-администратор** (дополнительно к правам администратора)
- Назначение и снятие прав администратора у других пользователей
- Просмотр списка всех администраторов
- Защита от самоудаления и от изменения собственных прав

Первый пользователь, запустивший бота (`/start`), автоматически получает статус супер-администратора.

### Машина состояний (FSM)

Процесс бронирования управляется конечным автоматом на базе `aiogram.fsm`:

```
CHOOSE_WORKPLACE → CHOOSE_DATE → CHOOSE_DURATION
```

Отдельный набор состояний `AdminStates` покрывает административные сценарии: добавление/удаление рабочего места, добавление/удаление администратора, отмена бронирования.

### Интерактивный календарь

Модуль `calendars.py` строит inline-клавиатуру с учётом уже занятых дат для конкретного рабочего места. Прошедшие и занятые даты помечаются символом ❌ с заблокированным callback, доступные — активной кнопкой вида `select_date_YYYY-MM-DD`. Переключение между месяцами — через callback `change_month_YYYY-MM`.

## Схема базы данных

База данных `booking_bot` создаётся автоматически при первом запуске (`Database.create_tables()`).

| Таблица | Поле | Тип | Описание |
|---|---|---|---|
| **users** | `user_id` | BIGINT (PK) | Telegram ID пользователя |
| | `username` | VARCHAR(100) | Никнейм, обновляется при каждом `/start` |
| | `is_admin` | BOOLEAN | Флаг администратора |
| | `is_super_admin` | BOOLEAN | Флаг супер-администратора |
| **workplaces** | `workplace_id` | SERIAL (PK) | Идентификатор места |
| | `name` | VARCHAR(100) | Название рабочего места |
| **bookings** | `booking_id` | SERIAL (PK) | Идентификатор брони |
| | `user_id` | BIGINT (FK → users) | Кто забронировал |
| | `workplace_id` | INTEGER (FK → workplaces) | Какое место |
| | `start_date` / `end_date` | DATE | Период бронирования |
| | `created_at` | TIMESTAMP | Время создания записи |
| **logs** | `log_id` | SERIAL (PK) | Идентификатор записи журнала |
| | `user_id` | BIGINT (FK → users) | Кто выполнил действие |
| | `action` | VARCHAR(255) | Описание действия |
| | `created_at` | TIMESTAMP | Время записи |

### Предотвращение конфликтов бронирований

Проверка пересечения дат выполняется прямым SQL-запросом с использованием стандартного оператора PostgreSQL `OVERLAPS`:

```sql
SELECT 1 FROM bookings
WHERE workplace_id = %s
AND (start_date, end_date) OVERLAPS (%s, %s)
```

Если хотя бы одна пересекающаяся запись найдена — создание новой брони блокируется.

## Установка и запуск

### 1. Клонирование и виртуальное окружение

```bash
git clone https://github.com/<artoutsaur>/booking-system-bot.git
cd booking-system-bot
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настройка базы данных

Создайте PostgreSQL-базу (структура таблиц создастся автоматически при первом запуске):

```sql
CREATE DATABASE booking_bot;
```

### 3. Переменные окружения

Скопируйте `.env.example` в `.env` и заполните реальными значениями:

```
BOT_TOKEN=your_bot_token_here
DB_HOST=localhost
DB_PORT=5432
DB_NAME=booking_bot
DB_USER=postgres
DB_PASSWORD=your_db_password_here
```

Токен бота получается через [@BotFather](https://t.me/BotFather).

### 4. Запуск

```bash
python bot.py
```
